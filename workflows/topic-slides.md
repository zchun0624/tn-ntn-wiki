# Workflow：主題 → 教學 HTML 簡報（topic-slides）

> 用法：對 AI 說「照 workflows/topic-slides.md，主題：＿＿＿」。
> 只能用 wiki 的內容，不可以用自己的知識補。所有中間產物放在 `slides/<slug>/`，每一關都能單獨重跑。

## 流程圖（graph）

```
① 檢索 wiki ─→ [A 覆蓋率關卡] 任一子題相關頁 < 2 頁，或全部 < 3 頁 → 停下回報
      ↓
② 證據卡（每張卡只看一頁 wiki）
      ↓
③ 大綱 ─→ [B 人工確認] 使用者看大綱；退回 → 修大綱，或回 ① 補檢索
      ↓
④ 逐頁稿 ─→ [C 程式檢查] check_slides.py --stage drafts
      ↓        退回 → 只修出錯那頁（每頁最多 2 輪）
      ↓ ─→ [D AI 忠實度審查] 另開新的 AI，只給逐頁稿＋證據卡
      ↓        退回 → 只修那頁；卡片本身錯 → 回 ② 重做那張卡
⑤ 渲染 HTML ─→ [E 渲染檢查] check_slides.py --stage render（截圖、溢出、頁數）
      ↓        退回 → ④ 縮短那頁
⑥ 交件：deck.html ＋ report.md（每關的檢查紀錄）
```

## 每一關只能看什麼、不能做什麼

| 節點 | 只能看 | 不能做 |
|---|---|---|
| ① 檢索 | `wiki/index.md` 與 wiki 頁面 | 讀 `raw/` 原始 PDF |
| ② 證據卡 | 一頁 wiki | 混入其他頁或自己的知識 |
| ③ 大綱 | 證據卡清單 | 寫入卡片以外的子題 |
| ④ 逐頁稿 | 大綱＋該頁引用的卡片 | 引用卡片以外的內容 |
| ⑤ 渲染 | 已通過 C、D 的逐頁稿 | 改任何一個字 |
| 檢查關卡 | 成品＋來源 | 自己動手改 |

## 完成標準（C、E 關由腳本判定）

1. 每頁有出處：引用的卡片必須存在，格式 `〔卡:<卡片名>#F<編號>〕`。
2. **數字比對**：頁面上的每個數字，都要在該頁引用的卡片事實裡找得到。
3. **爭議數字**：wiki 裡 ⚠️ 區塊「說法」行中的數字，如果沒出現在「目前結論」，簡報不可以使用。
4. **術語**：每個縮寫在整份簡報第一次出現時，要用全形括號附中文說明，例如「低軌衛星（LEO）」。
5. **易懂**：每個概念頁至少有一句生活比喻（取自 wiki 的「一句話白話解釋」）；至少 3 頁有示意圖。
6. 8～15 頁；渲染後每頁都沒有文字溢出。

## 剎車

- 任一關改滿 3 輪還沒過 → 停下，把問題寫進 `report.md` 交給使用者。
- 覆蓋率不足 → 一開始就停，不硬湊。
