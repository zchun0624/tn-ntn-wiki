# 卡：3GPP 標準怎麼制定（3GPP Standardization）

> 來源頁：`wiki/concepts/3gpp-standardization.md`（只讀這一頁，原句照抄）

- F1｜一句話白話解釋｜3GPP 是全球電信業者一起訂規則的組織：先「研究」寫成報告，大家同意後再「正式立項」寫成規格，每隔一段時間打包成一個版本（Release）[tutorial2024, p.6]。
- F2｜詳細說明｜**3GPP 是什麼**：第三代合作夥伴計畫（3rd Generation Partnership Project, 3GPP），1998 年由 7 個電信標準組織成立；名字保留「3G」，但現在已經在做 5G、6G [tutorial2024, p.5]。
- F3｜詳細說明｜**三個技術規格組（TSG）**：無線接取網路（RAN）、服務與系統（SA）、核心網與終端（CT）[tutorial2024, p.5–6]。
- F4｜詳細說明｜**工作組（WG）**：每個 TSG 底下再分工作組，依序編號，例如 RAN1～RAN5、SA1～SA5 [tutorial2024, p.6]。
- F5｜詳細說明｜**研究項目（Study Item, SI）**：事前研究，結果寫成技術報告（TR），例如 TR 22.822 [tutorial2024, p.6]。
- F6｜詳細說明｜**工作項目（Work Item, WI）**：研究有共識後才立項，結果發布成技術規格（TS）[tutorial2024, p.6]。
- F7｜詳細說明｜**版本（Release）**：一個 Release 由多份 TS 組成，完整描述整個系統；同一主題通常 SI 在前一版、WI 在後一版 [tutorial2024, p.6]。
- F8｜詳細說明｜**NTN 的例子**：Rel-15、Rel-16 都是 SI（研究通道模型和解法），Rel-17 才變成 WI（正式規格）[lin2021, p.7]。
