# 地面網路和非地面網路比較（TN vs NTN）

> 類型：比較頁｜來源：3gpp2025、lin2021、tutorial2024、jeon2026｜更新：2026-11-23

## 一句話差別

地面網路（Terrestrial Network, TN）近、快、容量大，但只蓋得到有基地台的地方；NTN 從天上蓋，範圍大，但延遲長、衛星會移動 [3gpp2025, p.3–4]。

## 比較表

| 項目 | 地面網路（TN） | 非地面網路（NTN） | 出處 |
|---|---|---|---|
| 基地台位置 | 地面 | 衛星、高空平台，或地面閘道站（透明式時） | [3gpp2025, p.4–5] |
| 傳播延遲 | 通常 <1 ms | GEO 可達數百 ms | [3gpp2025, p.4] |
| 細胞大小 | 較小 | 較大，延遲差異與遠近效應更明顯 | [3gpp2025, p.4] |
| 細胞是否移動 | 固定 | LEO、MEO 的細胞會移動；GEO 相對穩定 | [3gpp2025, p.3–4] |
| 都卜勒頻移 | 小 | LEO、MEO 較大，變化也較快 | [3gpp2025, p.4] |
| 多路徑傳播 | 常見，角度擴散大 | 路徑幾乎平行，角度擴散接近 0 | [lin2021, p.2] |
| 覆蓋與國界 | 通常只在一個國家內 | 可能跨越多國或公海 | [lin2021, p.4] |
| 上行時序 | 依下行接收時間即可 | 需要 GNSS 位置與星曆預補償 | [lin2021, p.3] |
| 成本 | 較低 | 較高 | [tutorial2024, p.16, Table I] |
| 資料速率 | 較高 | 較低 | [tutorial2024, p.16, Table I] |
| 可靠性 | 穩固 | 較脆弱 | [tutorial2024, p.16, Table I] |
| 偏遠地區 | 到不了 | 到得了 | [tutorial2024, p.16, Table I] |
| 覆蓋範圍 | 區域性 | 全球 | [tutorial2024, p.16, Table I] |

> ⚠️ 說法不一致
> - 說法 A：TN 是「頻繁換手」，NTN 是「無縫移動」[tutorial2024, p.16, Table I]。
> - 說法 B：LEO 衛星移動快，會造成 NTN 頻繁換手，需要加強換手機制 [lin2021, p.3]、[3gpp2025, p.11]。
> - 可能原因：tutorial2024 的表格可能是從「覆蓋範圍大、使用者不必在小細胞之間切換」的角度看；但 lin2021 和 3gpp2025 討論的是 LEO 衛星移動造成的換手。
> - 目前結論：以 3GPP 官方為準，LEO／MEO 的 NTN 需要處理頻繁換手；只有 GEO 相對地面穩定 [3gpp2025, p.3, p.11]。

## 什麼時候用哪一個

- 地面網路服務不到或不可靠的地方（鄉村、海上、空中、災區）用 NTN 補位 [3gpp2025, p.6]。
- 大範圍的廣播或多播，用 NTN 比較有效率 [3gpp2025, p.6]。
- 兩者可以整合：3GPP 要求 5G 支援地面與衛星接取之間的服務連續性，也要能同時使用兩種接取 [3gpp2025, p.12–13]。
- UE 可以在兩者之間換手，但 Rel-17 不要求同時連到兩者 [3gpp2025, p.16]。
- 整合 NTN 和地面網路，是在偏遠地區提供大範圍覆蓋最實際、最划算的方法 [tutorial2024, p.15]。
- Rel-19 的 DualSteer 讓 UE 同時維持兩條連線，由網路決定流量走哪一條，詳見[TN 和 NTN 怎麼整合](../concepts/tn-ntn-integration.md) [jeon2026, p.1]。
- 反過來，NTN 在建築物內、森林、人口密集城市的覆蓋有限，需要地面網路補足 [tutorial2024, p.65]。
